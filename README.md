# 3310 — Лендинг для сервиса расшифровки аудио

Лендинг-страница для сервиса 3310 — платформы для расшифровки аудио в текст без переплат с единовременной оплатой.

## О проекте

3310 — это сервис для расшифровки аудио с уникальной бизнес-моделью:
- Разовая оплата вместо подписки
- 135 часов расшифровки включены в стоимость (3310₽)
- После использования 135 часов — всего $0.34 за час расшифровки
- Экономия до 90% по сравнению с другими сервисами

## Технические особенности

- Чистый HTML/CSS без зависимостей
- Адаптивный дизайн для всех устройств
- Оптимизирован для быстрой загрузки
- Готов к деплою на любом хостинге

## Деплой

Лендинг можно развернуть с помощью:

### Vercel

1. Импортируйте этот репозиторий в Vercel
2. Настройте проект (настройки по умолчанию подойдут)
3. Нажмите Deploy

### GitHub Pages

1. В настройках репозитория перейдите в раздел Pages
2. В качестве Source выберите main ветку
3. Сохраните настройки и дождитесь деплоя

### Netlify

1. Создайте новый сайт из Git
2. Выберите этот репозиторий
3. Настройки сборки можно оставить по умолчанию
4. Нажмите Deploy site
